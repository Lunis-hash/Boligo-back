# Offre partenaires BOLIGO : visibilité, suivi, rentabilité

Ce document répond à quatre questions, pour chaque profil (marque, ambassadeur,
créateur) : **comment on fait du business ensemble**, **comment le partenaire
apparaît sur le site**, **comment on mesure ses clics et son impact**, et
**ce qu'on lui propose réellement**. Il complète
[PROGRAMME_PARTENAIRES.md](PROGRAMME_PARTENAIRES.md) (candidature,
vérification, règles juridiques).

Principe directeur : **tout ce qui est promis sur la page `/partenaires` existe
dans le produit et se mesure**. Aucune donnée de membre n'est jamais transmise.

## 1. Ce que chaque profil reçoit

| | Marque / annonceur | Ambassadeur commercial | Créateur / influenceur |
|---|---|---|---|
| **Visibilité dans BOLIGO** | « Partenaire du mois » sur la page d'accueil ; offre dans la page « Offres partenaires » des membres (Profil → Offres partenaires) | Bandeau « Recommandé par … » vu par chaque visiteur arrivé par son lien | Idem ambassadeur |
| **Outil** | Offre (titre, avantage, description, lien https, code marque facultatif), période de diffusion | Lien suivi `…/?p=CODE` + code personnel | Lien suivi + code (10 % pour l'audience par défaut) |
| **Mesure** | Affichages, clics, taux de clic, par jour ; visites reçues chez la marque avec `utm_source=boligo`, `utm_medium=offre_partenaire`, `utm_campaign=<offre>` | Visites du lien → inscriptions → Parcours payés, taux de conversion, mois par mois | Idem ambassadeur |
| **Rémunération** | Aucune commission : la marque paie sa visibilité (contrat et facture au cas par cas) | **20 %** du montant encaissé avec son code | **15 %** du montant encaissé avec son code |
| **Tableau de bord** | Espace partenaire : statistiques de ses offres | Espace partenaire : lien, tunnel, ventes, commission, kit prêt à publier | Idem ambassadeur |

## 2. Le parcours d'un visiteur venu d'un partenaire

1. Le créateur publie son lien `https://boligo-web.onrender.com/?p=AWA10`
   (avec la mention « Collaboration commerciale »).
2. Le visiteur arrive : le site vérifie le code, affiche **« Recommandé par Awa
   Média : -10 % sur votre premier parcours »** et compte **une visite** (une
   seule par session de navigation).
3. Le code reste sur l'appareil **30 jours au plus** (stockage local, pas de
   cookie publicitaire, pas de traceur tiers).
4. À l'inscription, le compte est rattaché au partenaire : **une inscription**
   est comptée.
5. Au paiement (jusqu'à **90 jours** après l'inscription), le code est
   **prérempli et vérifié automatiquement** : « Offert grâce à Awa Média ».
6. Le paiement payé compte dans les ventes et la commission du partenaire. Un
   remboursement est **déduit automatiquement**.

Si le membre saisit lui-même un autre code, c'est ce code qui s'applique : il
garde toujours la main.

## 3. Ce que voit chaque partie

| Qui | Voit | Ne voit jamais |
|---|---|---|
| Partenaire (Espace partenaire) | Totaux par jour et par mois : visites, inscriptions, Parcours payés, montant, commission, affichages et clics de ses offres | Nom, e-mail, profil, date précise d'achat d'un membre |
| Marque (sur son propre site) | Les visites venues de BOLIGO, grâce aux paramètres `utm_` | Qui a cliqué |
| Équipe BOLIGO (tableau de bord) | Tout ce qui précède + gestion des offres (créer, publier, retirer) | — |
| Membre | La mention « Publicité » sur chaque offre ; le nom du partenaire qui l'a recommandé | — |

## 4. Rentabilité, pour BOLIGO comme pour le partenaire

Chiffres par membre (un Parcours Harmonie = 15 € TTC payé par chaque membre ;
coûts variables d'un parcours divisés par deux, voir
[COUT_PARCOURS.md](COUT_PARCOURS.md)) :

| Cas | Encaissé TTC | Commission | Reste à BOLIGO, HT, après coûts variables (≈ 1,28 €) |
|---|---|---|---|
| Sans partenaire | 15,00 € | 0 | ≈ 11,22 € |
| Créateur (-10 %, 15 %) | 13,50 € | 2,03 € | ≈ 7,94 € |
| Ambassadeur (-10 %, 20 %) | 13,50 € | 2,70 € | ≈ 7,27 € |
| Code « Parcours offert » | 0 € | 0 (jamais de commission) | ≈ -1,60 € (coût d'acquisition) |

Lecture : un membre apporté par un partenaire reste **rentable, à 65-70 % de la
marge normale**, et le partenaire n'est payé que sur des ventes réelles,
remboursements déduits. Les Parcours offerts ne gonflent plus les ventes :
ils sont affichés à part (« Parcours offerts avec votre code »).

Pour le partenaire : 100 Parcours payés via son lien = **203 €** (créateur) ou
**270 €** (ambassadeur), visibles en direct.

Pour une marque : le prix de la visibilité se fixe au contrat. Base de
discussion : affichages et clics réellement mesurés (coût par mille affichages
ou par clic), ou forfait mensuel pour « Partenaire du mois ».

## 5. Indicateurs à suivre chaque mois

- **Visites → inscriptions** (taux d'inscription du lien) : sous 5 %, revoir le
  message du partenaire ou son public.
- **Inscriptions → Parcours payés** : mesure la qualité du public apporté.
- **Taux de clic des offres** : sous 0,5 %, changer l'avantage ou le visuel.
- **Parcours offerts / Parcours payés** par code : surveiller le coût
  d'acquisition.

## 6. Publier une offre de marque (équipe)

Tableau de bord → Partenaires → fiche du partenaire → **Offres dans BOLIGO** :

1. « Nouvelle offre » : titre, avantage, description, lien `https://` de la
   marque, code marque facultatif, emplacement, dates.
2. L'offre est enregistrée **hors ligne**.
3. « Publier » : possible seulement si le partenaire est **Accepté**.
4. Elle apparaît à l'emplacement choisi pendant sa période, avec la mention
   « Publicité ». « Retirer » la cache aussitôt.

Le lien du partenaire (`…/?p=CODE`) s'affiche aussi sur sa fiche, pour le lui
transmettre.

## 7. Protection des données

- Aucun cookie publicitaire, aucun pixel, aucun traceur tiers.
- Compteurs **agrégés par jour** (`PartnerDailyStat`, `PartnerOfferStat`) :
  jamais d'adresse IP, d'identifiant d'appareil ou de lien avec un membre.
- Seul lien individuel : le compte d'un membre garde le code du partenaire
  qui l'a recommandé (`User.referralCodeId`, `User.referredAt`), pour lui
  appliquer la réduction promise. Ce lien n'est jamais montré au partenaire.
- Le code conservé 30 jours sur l'appareil du visiteur sert à lui accorder la
  réduction annoncée. **À faire valider par le conseil juridique** : exemption
  de consentement (traceur nécessaire au service demandé) ou mention dans le
  bandeau d'information.
- Les limites anti-abus : 120 requêtes de suivi par adresse IP toutes les
  10 minutes ; liens d'offres en `https` uniquement, sans identifiants.

## 8. Prochaines étapes (non faites)

- **Relevé des commissions versées** : aujourd'hui la commission se calcule
  à la volée ; un relevé mensuel figé (montant, date de versement, facture du
  partenaire) éviterait toute contestation.
- **Taux figé à la vente** : si l'équipe change le taux d'un partenaire, le
  nouveau taux s'applique à tout l'historique ; il faudrait enregistrer le
  taux au moment de chaque vente.
- **Lettre d'information** : aucune campagne d'e-mails n'est envoyée ; la
  visibilité d'une marque dans une lettre n'est donc pas proposée tant
  qu'elle n'existe pas.
