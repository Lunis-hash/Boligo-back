# BOLIGO Sondeur — English writing brief

BOLIGO is a serious dating app. The "Sondeur" asks the SAME question to two members who have just been matched and will read each other's answers. Each French string below must get an English version written by a native-level writer — natural, warm, plain international English (avoid heavy Americanisms or Britishisms), NOT a word-for-word translation. Rewrite freely so it sounds like something a thoughtful English-speaking relationship coach would ask.

Hard rules (same as the French):
- Address the reader as "you" (singular reader; the question is shown to each member separately). Never "you both" unless the French says "tous les deux"/"vous deux" in a statement of agreement.
- Never presuppose a fact, feeling, behaviour, past event or disagreement that the French does not presuppose. Keep conditionals ("would", "if") where the French uses the conditional.
- Keep the same meaning, the same technique (origin / need / limit / projection / scale 0–10 / circular question…), the same single idea per question.
- Questions end with "?"; statements end with "."; at most 180 characters for a question.
- No jargon, no labels, no diagnosis, no moralising, no yes/no question if the French is open.
- Gender-neutral: use "your partner", "the other person", "they"; never he/she. Where the French writes "respecté(e)", just write "respected".
- Hidden answer options (short choices, 1–5 words) stay short, natural, parallel in form. "Autre..." is always "Other...".
- Keep typographic simplicity: straight apostrophes ('), no French quotes « ».
- Cultural content (dowry, Mahr, faith, extended family, polygamy, customary marriage) must stay respectful and neutral, exactly as in French. "dot" = "dowry"; "Mahr" stays "Mahr"; "mariage coutumier" = "customary marriage".

Output: a single JSON object mapping EACH French string exactly as given (same characters) to its English version. Every input string must appear as a key. Write it with the Write tool to the output path given, and reply only with "done N" where N is the number of entries.
